How Are Forecast Dates & Predictions Calculated in the System?
1. Forecast Reference Date ($T_0$): The base date when the PatchTST deep learning model was executed (e.g. today IST).
2. Forecast Target Date ($T_{\text{target}}$): The future target horizon date ($T_{\text{target}} = T_0 + \text{Horizon Days}$). For a 7-day horizon, $T_{\text{target}} = T_0 + 7$; for 15-day, $T_0 + 15$; for 30-day, $T_0 + 30$.
3. Consistency Guarantee: The Demand Forecasting module, Forecast Analytics, AI Reorder Alerts, Reports & Export, CSV Exports, and PDF Exports all query the same centralized table with zero off-by-one errors or timezone shifts.
